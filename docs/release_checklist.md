# Publication checklist

This directory is prepared for review, not automatically approved for public
distribution.

- Confirm the copyright holder permits publishing these selected files and
  the proposed repository name. Preserve the per-file notices and `LICENSE`.
- Review the exact public diff and repository metadata before pushing. The
  source snapshot has no paper draft, experiment data, model weights, dataset
  paths, host addresses, credentials, or deployment commands.
- Keep the README's non-runnable scope statement if files are added or moved.
  A complete executable release would need its own dependency, security,
  correctness, and support review.
- Re-check for private paths, endpoints, credentials, and generated artifacts
  after any later copy from MindData.
- Do not infer performance claims from this snapshot. Publish only separately
  reviewed experimental results with their workload and measurement scope.
